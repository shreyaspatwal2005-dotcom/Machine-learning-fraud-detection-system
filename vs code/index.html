Fraud Desk

Train a fraud classifier on labelled transactions, judge it with precision, recall and F1 instead of accuracy alone, then score new transactions. Everything runs in your browser, so your data never leaves this page.

1. Load transactions

Use a CSV with numeric feature columns and a 0/1 column named is_fraud, or generate a sample with about 1.6% fraud.

2. Train and evaluate

Stratified 75/25 split. Missing values are filled with the training median. Models: a baseline that always says legitimate, logistic regression, and a random forest, both weighted for class imbalance.

Confusion matrix

Threshold trade-off

Precision, recall and F1 as the threshold moves.

3. Check a transaction

Enter feature values, or fill the form with the typical legitimate or fraudulent profile from the training data. The is_fraud column is never an input.

4. Test cases

Eight sample transactions with the result we expect, plus validation checks that bad inputs are rejected. Run them against the trained models, or click Load to put a case into the form above.

Prediction test cases

Expected labels assume the random forest at threshold 0.50. Logistic regression flags more transactions as fraud, so it can fail the borderline case.

5. Test cases from the trained data

Model:

Up to three examples per outcome, spread from most to least fraud-like. A group with no rows means the model made no such outcome at this threshold. Load puts a row into the form in step 3.
